# 📊 Supply Chain Insight Dashboard | Microsoft Power BI

I'm excited to share my latest portfolio project:
a Supply Chain Insight Dashboard developed using Microsoft Power BI to analyze order and inventory data and support data-driven decision making. This project focuses on 1,200 orders from 7 active suppliers delivered to 5 warehouses between January 2025 and August 2026, providing insights into order cost, delivery performance, supplier reliability, and stock conditions. Key areas covered in this project include:

🔹 **Order Cost Analysis:** Analyzing total order cost, order volume, and monthly cost trends.

🔹 **Delivery Performance Monitoring:** Tracking order status, On-Time Rate against the 90% target, and average delivery delay.

🔹 **Category Analysis:** Identifying product categories with the highest order cost.

🔹 **Supplier Performance Analysis:** Comparing suppliers by the share of on-time and late deliveries.

🔹 **Inventory Monitoring:** Classifying stock into Normal, Low Stock, and Overstock across SKU and warehouse combinations.

Throughout this project, I applied Power Query, data modeling, DAX measures, and dashboard visualization to transform raw order and inventory data into meaningful insights for supplier evaluation and stock monitoring.

> **Note:** All data in this project is dummy data created for portfolio purposes.
